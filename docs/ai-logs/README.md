# AI logs

Reports produced by AI assistants about this repository — audits, reviews, and
analyses that informed decisions but are not themselves book content.

They are kept for the same reason lab notebooks are kept: a recommendation that
shaped the book should be inspectable later, including the parts that were
**not** acted on and why. Each file records the tool, the date, and the commit
of the repository it describes.

These are inputs to judgment, not authority. An AI audit can be confidently
wrong, and several claims in these files were checked against primary sources
before being accepted. Where a recommendation was rejected or modified, the
issue or pull request that decided it is the record.
