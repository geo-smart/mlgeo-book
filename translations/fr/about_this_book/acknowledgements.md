## Assistance de l'IA

Certains brouillons de tutoriels de l'édition 2024 se sont appuyés sur ChatGPT. L'édition 2026 a été révisée avec l'aide d'un assistant IA agentique (Claude), tout le contenu ayant été relu par les enseignants. Les jeux de données et le code sont attribués là où ils apparaissent dans le livre.
