## Les carnets Jupyter

Le projet Jupyter est un projet open source à but non lucratif qui soutient le calcul interactif pour la science des données et le calcul scientifique. Il prend en charge plus de 100 langages de programmation.

Un **carnet** (*notebook*) Jupyter réunit dans un même document du texte (écrit en Markdown, voir plus bas), des images, du HTML, du LaTeX, du code et les sorties de ce code. Sous le capot, c'est un fichier JSON. Le carnet se compose de *cellules*, de code ou de texte.

Un **noyau** (*kernel*) Jupyter est le processus, propre à chaque langage, qui exécute le code contenu dans un carnet.

Les **cellules** peuvent être exécutées une à une, ou depuis le menu : *Run* -> *Run all cells*, ou *Kernel* -> *Restart Kernel and Run All Cells*. Redémarrer le noyau et tout exécuter de haut en bas est le test honnête d'un carnet : il débusque les cellules qui ne fonctionnaient que grâce à l'état caché d'expériences antérieures.

## JupyterLab

JupyterLab est une interface de navigateur élargie qui réunit carnets, terminal, visionneuses de fichiers (CSV, JSON, images) et d'autres outils.

## JupyterHub

Un JupyterHub est un JupyterLab servi depuis du matériel partagé. L'utilisateur voit parfois dans la barre d'adresse où se trouve l'ordinateur, sans nécessairement savoir quel matériel tourne dessous. Exception : le choix du type d'instance sur les clouds publics.

## Les carnets dans VS Code

VS Code ouvre, édite et exécute nativement les fichiers `.ipynb` : il se connecte aux mêmes noyaux Jupyter et ajoute, à côté du carnet, un terminal intégré, un débogueur et la prise en charge de Git. Une grande partie de ce livre a été écrite ainsi. Dans ce cours, JupyterLab et VS Code sont interchangeables ; VS Code est l'habitat le plus courant des assistants IA décrits ci-après.

## Le carnet, espace de travail partagé avec un assistant IA

En 2026, un assistant IA agentique installé dans votre éditeur ou votre terminal peut lire votre carnet, exécuter des cellules, inspecter les sorties et modifier le code — le carnet devient un espace de travail que vous partagez avec l'assistant. C'est utile : l'assistant voit le vrai message d'erreur ou la vraie figure, pas votre paraphrase.

Deux conséquences. D'abord, l'hygiène du carnet compte plus, pas moins : un assistant qui lit un carnet dont les cellules ont été exécutées dans le désordre hérite de la même confusion que vous. Ensuite, vous restez responsable de chaque sortie. Que l'assistant exécute une cellule ne vaut pas vérification du résultat par vous — contrôlez les nombres, les axes et les unités avant de construire dessus. La politique du cours sur l'usage de l'IA est en [1.8](1.8_ai_in_your_workflow.md).

## Markdown

### Qu'est-ce que Markdown ?
Un langage simple de mise en forme du texte.

Utilisé pour :
* le texte des carnets Jupyter ;
* le texte des fichiers `.md` sur GitHub (p. ex. le README.md d'un dépôt) ;
* le texte des fichiers RStudio.

### Commandes Markdown de base

Titres <br>

\# Titre de niveau 1 <br>
\#\# Titre de niveau 2 <br>
\#\#\# Titre de niveau 3 <br>


Paragraphes : laissez une ligne vide

Voici mon premier paragraphe.

Voici mon second paragraphe.
***


Texte en gras<br>

\*\*Voici mon texte en gras\*\*
***

Texte en italique<br>

\*Voici mon texte en italique\*
***

Texte en gras et italique

\*\*\*Voici mon texte en gras et italique\*\*\*
***

Texte barré

\~\~Texte barré\~\~
***

Markdown accepte le **HTML**. Par exemple, on peut <u>souligner</u> un <u>texte</u> avec :

      <u>texte</u>
***

Saut de ligne : utilisez `<br>`<br>

Voici ma première ligne.<br>
Voici ma seconde ligne.
***


Liste ordonnée

1. Premier élément
2. Deuxième élément
3. Troisième élément
4. Quatrième élément
***

Liste non ordonnée

\- Premier élément <br>
\- Deuxième élément <br>
\- Troisième élément <br>
\- Quatrième élément <br>
***

Lier une URL, comme le [dépôt de données du cours](https://github.com/UW-MLGEO/MLGeo-dataset) :

      [dépôt de données](https://github.com/UW-MLGEO/MLGeo-dataset)
***

Insérer des images comme <img src="../img/GeoSMART_logo.svg" width="200"/>, avec

      <img src="glass.png" width="200"/>
***


LaTeX dans les cellules de texte :

      \sqrt{x}

peut donner ceci $\sqrt{x}$.
