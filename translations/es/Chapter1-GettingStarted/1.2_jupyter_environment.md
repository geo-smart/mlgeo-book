## Cuadernos de Jupyter

El Proyecto Jupyter es un proyecto de código abierto, sin fines de lucro, que sostiene el cómputo interactivo para la ciencia de datos y el cómputo científico. El proyecto soporta más de 100 lenguajes de programación.

Un **notebook de Jupyter** (**cuaderno** de Jupyter) combina texto (escrito en Markdown, vea abajo), imágenes, HTML, LaTeX, código y salidas de código en un solo documento. Por debajo es un archivo JSON. El cuaderno se compone de *celdas* que son de código o de texto.

Las dos palabras están en uso: quien investiga en español dice tanto «notebook» como «cuaderno», y los materiales universitarios hispanohablantes usan las dos. Ninguna es un error. Este libro da la glosa «notebook de Jupyter (cuaderno)» en la primera aparición de cada capítulo y después escribe *notebook*, que es la forma corriente en la prosa orientada a la investigación; la extensión `.ipynb` y los nombres de archivo nunca se traducen.

Un **kernel** de Jupyter es el proceso, específico de cada lenguaje, que ejecuta el código contenido en un cuaderno.

Las **celdas** pueden ejecutarse una por una, o desde el menú: *Run* -> *Run all cells*, o *Kernel* -> *Restart Kernel and Run All Cells*. Reiniciar el kernel y ejecutar todas las celdas de arriba abajo es la prueba honesta de un cuaderno: descubre las celdas que solo funcionaban por el estado oculto de experimentos anteriores.

## JupyterLab

JupyterLab es una interfaz de navegador ampliada que incluye cuadernos, una terminal, visores de archivos (CSV, JSON, imágenes) y otras herramientas.

## JupyterHub

Un JupyterHub es un JupyterLab servido desde hardware compartido. Quien lo usa puede ver dónde está la computadora en la dirección del navegador, pero puede no saber qué hardware corre por debajo. Una excepción es la selección de tipos de instancia en las nubes públicas.

## Cuadernos en VS Code

VS Code abre, edita y ejecuta archivos `.ipynb` de forma nativa: se conecta a los mismos kernels de Jupyter y agrega una terminal integrada, un depurador y soporte de Git junto al cuaderno. Buena parte de este libro se escribió así. En este curso puede usar JupyterLab o VS Code indistintamente; VS Code es el hogar más común de los asistentes de IA que se describen a continuación.

## El cuaderno como espacio de trabajo compartido con un asistente de IA

En 2026, un asistente de IA agéntica en su editor o terminal puede leer su cuaderno, ejecutar celdas, inspeccionar la salida y editar código — el cuaderno se convierte en un espacio de trabajo que usted comparte con el asistente. Esto es útil: el asistente puede ver el mensaje de error real o la gráfica real, no su paráfrasis.

De ahí siguen dos consecuencias. Primera: la higiene del cuaderno importa más, no menos — un asistente que lee un cuaderno con celdas ejecutadas fuera de orden hereda la misma confusión que usted. Segunda: usted sigue siendo responsable de cada salida. Que el asistente ejecute una celda no equivale a que usted verifique el resultado — revise los números, los ejes y las unidades antes de construir sobre ellos. La política del curso sobre uso de IA está en [1.8](1.8_ai_in_your_workflow.md).

## Markdown

### ¿Qué es Markdown?
Un lenguaje simple para dar formato a texto.

Se usa para:
* Texto en cuadernos de Jupyter
* Texto en archivos `.md` en GitHub (por ejemplo, el README.md de un repositorio)
* Texto en archivos de RStudio

### Comandos básicos de Markdown

Encabezados <br>

\# Encabezado de nivel 1 <br>
\#\# Encabezado de nivel 2 <br>
\#\#\# Encabezado de nivel 3 <br>


Párrafos: deje una línea en blanco

Este es mi primer párrafo.

Este es mi segundo párrafo.
***


Texto en negrita<br>

\*\*Este es mi texto en negrita\*\*
***

Texto en cursiva<br>

\*Este es mi texto en cursiva\*
***

Texto en negrita y cursiva

\*\*\*Este es mi texto en negrita y cursiva\*\*\*
***

Texto tachado

\~\~Texto tachado\~\~
***

Markdown admite texto en **HTML**. Por ejemplo, se puede <u>subrayar</u> un <u>texto</u> con:

      <u>texto</u>
***

Salto de línea: use `<br>`<br>

Esta es mi primera línea.<br>
Esta es mi segunda línea.
***


Lista ordenada

1. Primer elemento
2. Segundo elemento
3. Tercer elemento
4. Cuarto elemento
***

Lista sin ordenar

\- Primer elemento <br>
\- Segundo elemento <br>
\- Tercer elemento <br>
\- Cuarto elemento <br>
***

Enlazar una URL, como el [repositorio de datos](https://github.com/UW-MLGEO/MLGeo-dataset) del curso:

      [repositorio de datos](https://github.com/UW-MLGEO/MLGeo-dataset)
***

Para insertar imágenes como <img src="../img/GeoSMART_logo.svg" width="200"/>, use

      <img src="glass.png" width="200"/>
***


LaTeX en celdas de texto:

      \sqrt{x}

puede darnos esto: $\sqrt{x}$.
