# MLGeo visual-system assets

These assets were derived in August/September 2026 from the course flyer visual
direction and are intended for the MLGeo book, course materials, and Canvas
course. Text, navigation, and labels should remain live HTML or vector content;
they are deliberately not baked into these backgrounds.

## Files

- `mlgeo-scientific-landscape-hero.png` — wide, text-free website and slide hero.
- `mlgeo-scientific-landscape-portrait.png` — portrait/mobile background.

## Provenance

The source reference was the flattened August 12, 2026 flyer
`mlgeo-fall-2026-uw-flyer.png`. No layered source file was present. The clean
backgrounds were reconstructed with OpenAI image generation by removing the
flyer's typography, QR code, cards, and other foreground elements, then making
a dedicated landscape composition.

These generated assets contain no third-party tutorial diagrams, logos, or
characters. Keep UW and GeoSMART marks as separate, explicitly licensed vector
assets rather than merging them into the raster artwork.

## Design tokens

- Deep navy: `#070b36`
- Indigo: `#2b1763`
- Cyan: `#59d7ff`
- Gold: `#f7c843`
- Typography: modern sans serif, sentence case for instructional material
- Diagram convention: cyan = data/information flow; gold = model decision or
  objective; violet = learned state; warm orange = Earth process/energy
