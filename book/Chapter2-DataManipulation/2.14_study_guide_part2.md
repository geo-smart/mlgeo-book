## Session 6 (Mon Oct 12): Sampling, resampling, and irregular data

**Changing the sampling of a record is a claim about what happened between samples. Know what one value stands for, low-pass filter before you subsample, fill only the gaps the noise bounds and flag what you filled, and resample blocks when the noise has memory.**

You should be able to:

- Describe one value in a grid: variable, model level, grid spacing, time in UTC, and how much of it comes from the model. The NCEP/NCAR reanalysis value at Seattle is the lowest model level (about 40 m above the model's ground), a class B analysis, at grid points about 280 × 190 km apart, although the file says `level_desc: Surface` (2.5 Part 2; lec06 "Arrays that know their coordinates").
- Estimate the memory a grid needs from its shape and data type before you load it, and read its packing on disk: 16-bit integers with `scale_factor` 0.01 set the precision to 0.01 K (2.5 Part 1).
- Select a cell by coordinate with a tolerance of half the grid step, and catch the two silent traps: a latitude slice written south to north on a grid stored north to south returns nothing, and `method="nearest"` on a grid converted to -180 to 180° returns a cell in the Atlantic (2.5 Part 3; lec06 "Which cell is Seattle?").
- Convert units on a copy, update every attribute, add a `history` entry, and fingerprint the result so a rerun can show it is identical. Accept an agent's function only after your own check table passes, and log the exchange in `AI_logs/` (2.5 Parts 4 and 5).
- Tell statistical resampling (randomization, bootstrap, Monte Carlo) from signal resampling (changing the sampling rate or grid). Draw a bootstrap resample with replacement and of the same size as the sample, and say why the bootstrap cannot remove the bias of a small sample (2.6 section 1).
- Compute the Nyquist frequency of a series and predict where a higher frequency folds: M2 at 1.93 cycles per day folds to 0.068 cycles per day, a 14.8-day period, in a series kept once a day (2.6 section 3.1).
- Find out what the provider did before you downloaded: the native sampling, the distributed product, and what the product cannot recover (lec06 "One sensor, two samplings" and "Native and distributed resolution"; 2.6 section 3.1b). Convert local times to UTC with each reading's own time-zone code, so the repeated hour at the end of daylight saving time stays separate.
- Write a gap policy with a threshold set by the station's own signal rates, keep a `filled` flag and the `method` beside every filled value, and test a gap filler on gaps placed where real gaps happen (2.6 sections 3.2 to 3.2c).
- Average an irregular network without letting its composition change the result: subtract each site's own mean first, then weight by 1/σ² (2.6 section 3.3).
- Put an honest error bar on a trend in correlated noise with a moving-block bootstrap, and state the block length as a decision longer than the noise correlation time (2.6 section 3.4).

Key terms:

| Term | Meaning in this course |
|---|---|
| Reanalysis | A fixed forecast model run forward in time and pulled toward the observations available at each step: a complete grid, also where nobody measured (2.5 "The dataset") |
| Kalnay class B | A reanalysis variable that observations affect directly but on which "the model also has a very strong influence" (Kalnay et al. 1996; 2.5) |
| Tolerance | The largest distance a nearest-neighbor selection may accept. Half the grid spacing, 1.25° on the 2.5° grid, turns a silent wrong cell into a `KeyError` (2.5 Part 3) |
| Fingerprint | A SHA-256 hash of a file's bytes, or of the values and attributes of an array. A match proves you hold the same bytes as the recorded copy, not that the copy matches the provider's original (2.5 Part 1) |
| Randomization | Reassigning observations between two groups at random to build the distribution of a statistic under the null hypothesis that group labels do not matter (2.6 section 1.1) |
| Bootstrap | Redrawing a sample with replacement, at the original sample size, to estimate the sampling uncertainty of a statistic (2.6 section 1.2) |
| Monte Carlo | Simulating new data from a known or assumed statistical model rather than redrawing from a sample (2.6 section 1.3) |
| Nyquist frequency | f_N = 1/(2Δt), the highest frequency a series sampled at interval Δt can represent (2.6 section 3.1) |
| Aliasing | A frequency above the new Nyquist folds into a lower frequency when a series is subsampled, and looks like a signal that was never there (lec06 "Keep one sample a day") |
| Anti-alias filter | A low-pass filter applied before subsampling. A daily mean is a crude one (a 24-hour boxcar); `scipy.signal.decimate` applies a designed one (2.6 section 3.1) |
| Native and distributed resolution | What the instrument or model sampled, against what the provider publishes. Two neighboring grid cells can come from the same measurement (lec06 "Native and distributed resolution") |
| Mascon | A mass concentration: one of the 4,551 equal-area 3° caps behind JPL's 0.5° GRACE grid (lec06 "Native and distributed resolution", notes) |
| Gap policy | A stated threshold: fill gaps the noise bounds, mask longer ones as missing, write the threshold down (2.6 section 3.2) |
| Filled flag | A column that marks each filled value and the method that filled it, as FLUXNET2015 and ESA CCI soil moisture distribute (2.6 section 3.2b) |
| Per-site anomaly | Each well's (or station's) value minus its own mean, so datum offsets cancel before averaging (2.6 section 3.3) |
| Inverse-variance weight | Weight 1/σ² per observation, which minimizes the variance of the combined estimate (2.6 section 3.3) |
| Moving-block bootstrap | Resampling contiguous blocks of residuals so each resample keeps the noise correlation up to the block length (2.6 section 3.4) |

## Session 8 (Fri Oct 16): Repairing real data streams

**A repair counts when an independent measurement confirms it. Choose the filter phase for the task, filter each segment on its own and leave gaps missing with a guard interval, measure clock errors against a reference, and write every step into the processing history.**

You should be able to:

- Tell a step in a raw record from a seismic arrival with a travel-time model. At UW.RATT the Chignik P wave arrives about 357 s after 06:15 UTC; the first of eight steps comes at 755.09 s, during the surface waves (2.9 Part 1; lec08 "Zero-phase and causal filters at a step").
- Choose a causal or a zero-phase filter for a task and measure each on an onset of known time. Causal filters suit real-time detection and anything that happens before an onset; zero-phase filters suit offline alignment. Do not interpret small wiggles just before a sharp onset in zero-phase output (2.9 Part 2).
- Explain why a causal band-pass makes the cycles of the RATT P wave train arrive early while their envelope arrives late: group delay and phase delay differ near the lower corner (2.9 Part 2).
- Say how a filter someone else chose changes a value you would use: a high-passed accelerogram loses the permanent offset GPS records at Norcia, and common-mode filtering of GPS removes both a reported precursor and a signal planted to test it (lec08 "Filtered accelerogram and GPS" and "GPS common mode and a reported precursor").
- Filter a record with a gap segment by segment, leave the gap as NaN, and set a guard interval that scales with the longest period in the band (2.9 Part 3).
- Recognize each provider's fill value before filtering: zero after a careless merge, -1 in the Apollo archive, estimates flagged "e" at USGS (lec08 "Apollo 12 record" and "Estimated discharge under ice").
- Estimate offsets at known equipment dates from the NGL step list instead of fitting one line through a series with steps (lec08 "Outages and an antenna offset on Mount St. Helens").
- Measure a clock lag by cross-correlation and refine it between samples with a parabola. Tell an offset from a drift, and name a real reference: a co-located sensor, a neighbor station after removing the predicted travel-time difference, or ambient-noise correlation tracked day by day (2.9 Part 4; lec08 "Seafloor clock drift" and "A 270 s timing error at US.HDIL").

Key terms:

| Term | Meaning in this course |
|---|---|
| Causal filter | Uses only present and past samples (`sosfilt`): nothing appears before the input, but each frequency is shifted differently (2.9 Part 2) |
| Zero-phase filter | Runs forward then backward (`sosfiltfilt`): no delay, but a symmetric response that puts energy before a sharp onset, and a stopband that falls off twice as fast (2.9 Part 2; lec08 notes) |
| Group delay, phase delay | The delay of a short pulse's envelope and of a wave train's cycles. Near 1 Hz in the 1 to 10 Hz causal filter they are +0.27 s and -0.25 s (2.9 Part 2) |
| Second-order sections (sos) | The numerically stable form of a Butterworth filter, `signal.butter(..., output="sos")` (2.9 Part 2) |
| Step | A jump in the raw record from the instrument or digitizer, not from the ground. Its time is known from the raw samples, which makes it a test of what a filter does (2.9 Part 1) |
| Zero-fill | Filling missing samples with zeros, which turns each gap edge into a step the size of the record's value there (2.9 Part 3) |
| Guard interval | The stretch at each segment edge to leave out of later analysis because the filter still remembers the edge (2.9 Part 3) |
| Common mode | Motion shared by all stations of a network, such as reference-frame or orbit error (lec08 "GPS common mode and a reported precursor") |
| Clock offset, clock drift | A constant lag against a reference, and a lag that grows with time. Both are corrected segment by segment between clock resets (lec08 "Clock drift on the Moon and at a flux tower", notes) |
| Skew | The clock difference measured when an ocean-bottom seismometer is recovered (lec08 "Seafloor clock drift") |
| Processing history | The record that travels with the data: filter type, corners, poles, causal or zero-phase; gap start, end, fill value and guard interval; timing reference, lag, drift and correction applied (lec08 "Three problems and their corrections") |

## Session 9 (Wed Oct 21): Noise, signal and synthetic data

**Most of what you remove as noise is someone else's signal, and calling it noise is a decision tied to your question. Describe each contribution by its source, spectrum and distribution, then build synthetic data with a known answer to measure what each one does to your result.**

You should be able to:

- Read a day-long spectrogram and attribute each band to a source: the secondary ocean microseism near 0.15 Hz, cultural noise from 1 to 10 Hz that rises by day, and earthquakes crossing both (lec09 "One day of ground motion at Seward Park").
- Name for each unwanted contribution the field that measures it: the microseism for ambient-noise imaging and wave climate, traffic for the 2020 lockdown studies, atmospheric delay for water vapour, starspots for stellar physics (lec09 "Traffic and ocean waves", "Weather in InSAR images", "Instrument problems and nuisance signals"; 2.10 section 5).
- Tell an instrument problem from a nuisance signal and treat each accordingly: correct or mask the first and record it; model the second as a component or give it its own class (lec09 "Instrument problems and nuisance signals").
- Describe a noise record by two independent properties, its spectrum (white, flicker, AR(1), random walk) and the distribution of its values (Gaussian or heavy-tailed), and know that sign conventions for the spectral exponent differ between fields (2.10 section 5.1; lec09 "Two transients in four colors of noise", notes).
- Predict which transient a colored noise hides: a slow ramp disappears in flicker noise and a random walk, while a short pulse can stand out against a random walk (lec09 "Two transients in four colors of noise").
- Explain why one SNR number does not describe 2D noise without its spatial spectrum (lec09 "One deformation bowl under three kinds of 2D noise").
- Tell random label noise from class-dependent label noise, and name the science quantity a class-dependent error biases even when accuracy barely moves (lec09 "Wrong labels"; 2.10 section 5.6).
- Explain why a 3-sigma clip on a heavy-tailed quantity discards the largest earthquakes or the floods, the events you study (lec09 "Distributions of values").
- Build a synthetic version of your data from the six ingredients: a signal with known parameters kept as the answer, realistic noise, one nuisance from another source, one instrument problem from Session 8, the distribution of noise values, and a seed with disclosure of which samples are synthetic (lec09 "Building synthetic data with known truth"; 2.10 section 5).
- Make spectrum-matched noise and say what it does not copy: random phases keep the amplitude spectrum but make the values Gaussian, so a detector tuned on the twin meets more false alarms on the real record (2.10 sections 4.1 and 5.1).
- Measure a detection floor: set the threshold from noise alone, then count detections against SNR (2.10 section 4.4).
- Say when synthetic data are admissible: method development, benchmarking, disclosed augmentation, hidden test sets; never as the only validation of a claim about the Earth (2.10 section 7).

| White noise | Equal power at all frequencies; each sample independent of the last |

| STA/LTA | Short-term over long-term average detector (Allen 1978); the classical baseline any learned detector must beat (2.10 section 4.4) |

## Session 10 (Fri Oct 23): AI-ready data

**A dataset is AI-ready when it supports training a model and testing whether it works somewhere new. Score it on the 11 criteria with evidence another team can check, count independent units rather than rows, and name the axis along which the test set lies outside the training domain.**

You should be able to:

- Tell analysis-ready from AI-ready data, and explain why the first is necessary but not sufficient: a clean record from one station in one decade can fail every generalization test (lec10 "Analysis-ready and AI-ready"; 2.13 section 1).
- Repair a multi-gauge discharge table: convert ft³/s to m³/s (× 0.0283168), find the 91-day jump in the time base, replace -999 with NaN, and name the mechanism behind each gap (2.13 A2 and A3).
- Write a description of the dataset that a script reads back (YAML beside a Parquet copy), with units for every variable, the missing-value encoding, and the statement that the data are synthetic (2.13 A1 and A4).
- Count independent units (gauges, years, floods) and explain why they, not rows, limit what a model can learn (2.13 B1; lec10 "AI readiness: what the samples contain").
- Choose a score for a rare class: average precision, whose value for a random guess equals the flood fraction (2.13 B2).
- Estimate measurement noise from day-to-day differences on non-flood days and compute an SNR (2.13 B3).
- Judge an augmentation by asking whether the instrument could have recorded the transformed sample: new noise at the measured level passes; a time-reversed hydrograph fails (2.13 B4; lec10 "AI readiness: what a model can learn from").
- Compare two labelers and explain why their agreement is inflated by the many days on which both say "no flood" (2.13 B5).
- Build a within-domain training and validation set (whole gauge-months held out) and out-of-domain test sets along a statistical, a spatiotemporal and a physical axis, and explain why the scores differ (2.13 B7; lec10 "B7: partitioning").
- Prevent leakage by preprocessing: split first, then fit scalers, PCA, imputation and oversampling on the training set only (2.13 B7, "Leakage by preprocessing").
- Score a dataset with the agent version of the rubric, then check two of the assistant's scores yourself (lec10 "Score a dataset with the rubric" and "The rubric, written for an agent").

The rubric, as 2.13 section 1 prints it. Each criterion scores **0** missing, **1** present but incomplete, **2** another team can verify it, the scale of the Session 2 rubric:

| | Criterion | What it asks |
|---|---|---|
| A1 | Provenance | source, version or retrieval date, license, citation; synthetic parts disclosed |
| A2 | Homogenization | consistent units, reference frame, coordinates, time base and sampling; instrument or processing changes corrected or flagged |
| A3 | Quality and gaps | quality flags, missing, sentinel and censored values, and their mechanism documented |
| A4 | Structure and metadata | tidy tables or labeled arrays in a standard format, variables and units in a file a script can read |
| B1 | Diversity | how many independent units (stations, events, regions, years, instruments), not how many rows |
| B2 | Distribution | distribution of targets and inputs, imbalance and long tails, compared with the population the model will face |
| B3 | Noise characterization | instrumental noise separated from natural variability; a noise level or SNR estimate |
| B4 | Augmentation potential | physically valid transformations, and the ones that break the physics |
| B5 | Labels | source, quality, uncertainty, consistency; or the potential for self-supervised learning |
| B6 | Dimensionality | samples against features, input shape, variance captured by a few principal components |
| B7 | Partitioning potential | within-domain training and validation, out-of-domain test along a stated axis, leakage controlled |

Key terms:

| Term | Meaning in this course |
|---|---|
| Analysis-ready | A scientist can compute with the data without redoing the provider's work: provenance, homogenization, documented quality and gaps, standard format (lec10 "Analysis-ready and AI-ready") |
| AI-ready | The data also support training a model and testing whether it generalizes. In this course AI-ready and ML-ready name the same requirements (lec10 "Analysis-ready and AI-ready") |
| Independent unit | The unit that carries new information: a station, an event, a region, a year. Consecutive days of one flood are not independent samples (2.13 B1) |
| Informative missingness | A value missing because of the value itself, as a gauge lost at a flood peak; every peak statistic is then biased low (2.13 A3) |
| Average precision (AP) | Area under the precision-recall curve; a random guess scores the positive-class fraction (2.13 B2) |
| Valid augmentation | A transformation whose result the instrument could have recorded (lec10 "AI readiness: what a model can learn from") |
| Self-supervised learning | Training on structure in abundant unlabeled data (seasonality, recessions, continuous waveforms) before any label is used (2.13 B5) |
| Within-domain set | Training and validation drawn from the same domain; validation tests interpolation and is used to choose settings (2.13 B7) |
| Out-of-domain test | A test set outside the training domain along a stated axis; it tests generalization along that axis only (lec10 "What each partition tests") |
| Statistical axis | Distance in feature space to the nearest training sample, with features standardized on training statistics only. Meyer and Pebesma (2021) call the inside the area of applicability (lec10 "B7", notes; 2.13 B7) |
| Spatiotemporal axis | A later period or a region or station the model never saw (2.13 B7) |
| Physical axis | A different process, event size or physics, such as floods larger than any in training (2.13 B7) |
| Leakage by preprocessing | A statistic computed on all the data before splitting (mean, PCA basis, percentile, imputation value, oversampling) carries test information into training (2.13 B7) |
| Agent version of the rubric | The same 11 criteria rewritten so an assistant must quote evidence for every score and write "not found", scored 0, when there is none (lec10 "The rubric, written for an agent") |

## Five ideas that carry Chapter 2

1. **Plant the truth, grade the method, then trust it on real data.** The tide gauge, the GNSS outage, the damaged RATT copy, the Session 7 twins, the STA/LTA floor and the four synthetic gauges all let you measure an error because the answer was known.
2. **Keep what you changed visible.** A NaN for a gap, a `filled` flag, a guard interval, a processing history and a statement that samples are synthetic let the next person, or the next model, tell measurement from repair.
3. **Find out what was done before you downloaded.** USGS daily means, the digitizer's anti-alias filter, the "e" estimates under ice, NGL's step list and a reanalysis file that calls its lowest model level "Surface" all changed the number in the file before you opened it.
4. **Noise is defined by the question.** Write down the source, the spectrum and the distribution of each contribution you remove, and who would keep it.
5. **Count independent units and name the axis of your test.** Random splits of correlated samples flatter the score: biomass plots (R² 0.53 against 0.14), random hidden gaps against the real outage, day-by-day against block bootstrap, validation months against gauge G4.
